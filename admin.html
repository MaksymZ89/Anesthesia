Admin access

This is a client-side password gate — it deters casual visitors but is not strong security, since this page runs entirely in the browser with no server. Don't put highly sensitive information into rules.txt.

Editing here changes what you see below, but it does not save back to your GitHub repository automatically. After editing, click Download rules.txt and replace the file in your project (then commit & push, or re-upload it wherever the site is hosted).

Syntax reference

IF <field> <operator> "<value>" THEN <ACTION> "<text>"

fields:     sex | age | illness | medication
operators:  CONTAINS | EQUALS | > | >= | < | <=
actions:    ADD_CONSULTATION | ADD_NOTE | ADD_WARNING
join conditions with AND. Lines starting with # are comments.

Example:
IF illness CONTAINS "Heart failure" THEN ADD_CONSULTATION "Cardiology consultation required."
IF medication CONTAINS "ACEI" AND age >= 65 THEN ADD_NOTE "Withhold ACE inhibitor on day of surgery; monitor closely given age."

Change admin password

Open admin.js in the project files, set NEW_PASSWORD near the top to your desired password, open this admin page once, open the browser console, copy the printed hash, paste it into the PASSWORD_HASH constant, then remove what you set in NEW_PASSWORD. Instructions are repeated as comments inside admin.js.
